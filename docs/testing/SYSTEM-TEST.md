Sources: requirements in `SOFTWARE_DEVELOPMENT_PLAN.md` (SDP) §2, §4 and §10; use cases in `docs/report/diagrams/fig-3-2-use-case.puml`; task flows in `docs/UX_API_SPEC.md` §5; master plan in `docs/testing/TEST-PLAN.md`; acceptance walkthroughs in `docs/testing/UAT.md` (in the repository; see its section 9).

This document specifies tests. Its own run results are the hosted results in §6A (ST-H), and each one cites its source record. The Status column states whether evidence exists now, not whether a test has passed. Other run results go to `docs/testing/test-cases.csv` (TEST-PLAN §13).

Status key:
- **Evidence exists**: a test file with a matching name exists under `apps/*/test` and is listed in its package test script, so CI runs it.
- **Partial**: some expected results have no matching file, the evidence is local only, or a limit in the design is not covered.
- **Not evidenced**: no test file, run record or measurement was found.
- **Points only**: the requirement was narrowed to points by owner decision (16 Nov 2026; F-01, F-12). The boundary check is out of scope, so it is not a gap. Rows with this status say "Points only" and give the decision.

## 1. Scope

- **In scope.** Local live mode (`npm run serve:live`; LIVE-LOCAL-01, accepted as local live mode on 8 Nov 2026, `docs/IMPLEMENTATION_BACKLOG.md`). The synthetic demo (`DATASET_MODE=demo`), labelled as demo in every view. Through these modes: the public web app (`apps/web`), the Worker API (`apps/worker`), the database (`apps/db`) and the intelligence poller (`apps/intelligence`).
- **In scope since 17 Nov 2026: hosted production.** The Cloudflare Workers Free and Neon Free site with `DATASET_MODE=live` (§2 and §6A). Its checks are smoke checks, read-only walkthroughs and a public phone check. On 18 and 19 Nov 2026 they also include the EXPLORE-18 read and write walkthroughs and API checks of the fixes (§6A). Hosted use runs under the rights limitation in ADR-065 (`local_relaxed`), and no source-rights clearance is claimed.
- **Out of scope, marked not tested.** Hosted backup, restore and deletion replay (`docs/PLATFORM_COMPATIBILITY.md`). The Android reader (`apps/mobile`) is out of scope for device tests; its Flutter analysis and test results are local evidence only (`.codex-build/ci-logs/cec9358/SUMMARY.md`).
- **Requirement baseline.** SDP §4: FR-02 to FR-16 (FR-01 withdrawn on 13 Nov 2026) and NFR-01 to NFR-08. User stories come from SDP §2 and verification areas from SDP §10.
- **Documentation conflict (resolved 18 Nov 2026).** SDP §3.1 used to describe a read-only moderator view with no sign-in. By owner decision of 18 Nov 2026 it now describes the signed-in moderator review the app implements (password accounts, ADR-060; authenticated moderation, `apps/worker/test/moderation-api.test.ts`). F-07 in `DEFECTS.md` is closed.

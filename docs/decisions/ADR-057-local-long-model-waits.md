# ADR-057 — Long model waits in the local synthetic pipeline

Status: accepted locally 12 October 2026 following the user's explicit deadline change and independent Luna/max review. Parent RAG-01/JOB-01 remain in progress.

Local real once/resume requests need more than the previous 25/26-second pair. Use 15 minutes per request, configurable down to 1 second through a backend-only local setting, with a processor fallback 1 second later. This selects the user's long-timeout alternative; it does not claim an infinite or upstream-unlimited request. Existing Worker/smoke defaults and L3 budgets do not change.

Use the existing native Node HTTP transport for local long requests, underneath the provider's explicit deadline/cancellation, to avoid an unrelated shorter fetch transport limit. Preserve source/schema/byte/token limits, the maximum three-request attempt and explicit extraction output policy. Timeout policy is part of state ownership, with the old 25-second profile preserved for historical read/resume compatibility.

Renew only the exact current private AI lease during long waits. Keep its five-minute duration and use fenced, nonoverlapping renewals every 60 seconds for waits above 60 seconds; loss/expiry must deny late writes and further calls. Renewal changes expiry/update time only, preserves attempts/provenance, cannot revive expired state or shorten expiry, and checks the exact synthetic source/snapshot and current token. Stop/join timers and transport on cancellation and resource cleanup. Crashes without renewal remain recoverable under existing lease expiry/backoff. A request can repeat after an unrecorded response; this is not exactly-once inference or proof the upstream stopped.

Forward closed provider observations to the root-only synthetic probe so timeout, cancellation, transport, HTTP and invalid-response outcomes can be distinguished without raw errors. Publication and real sources remain disabled. The provider's undefined/default policy remains 30,000 ms; its numeric ceiling is now 900,000 ms. Local real once/resume uses 900,000/901,000 ms unless the explicit integer override selects a shorter policy. Explicit 25,000 preserves the exact legacy profile; changed timing otherwise changes state ownership. Mocks do not read secrets or select the long policy. Existing smoke/L3/public defaults remain unchanged.

Root's WSL checks passed: isolated pipeline 58/58, Worker 519/519, evaluation/AI 41/41, workspace/tool typechecks, Vite/Worker dry-run build and smoke. Controlled-time tests prove completion beyond the original five-minute lease, denied late writes after failed renewal, expiry recovery, cancellation and timer cleanup. Independent review also verified body-phase abort, oversized/late response disposal and pre-abort with no HTTP/unhandled rejection. No new dependency, schema, grant or hosted setting changed.

Exactly one fresh authored-synthetic real attempt made three requests, all HTTP200: extraction 45.717s, embedding 0.961s and reasoning 22.539s. It renewed once and persisted all five stage receipts and one private proposal with **zero claims and one unresolved item**; publication tables remained empty. Three read-only desktop/mobile/refresh browser groups passed. Total 98.806s includes database work and is not inference latency. This demonstrates local transport/composition on one sample, not useful-claim quality, a pinned upstream model, full live smoke or real-source readiness. The older transport failure's cause remains unknown.

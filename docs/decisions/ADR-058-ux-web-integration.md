# ADR-058 — integrate web landing and read-only operations

Date: 13 October 2026. Status: accepted locally after independent Luna/max review and root verification.

The user requested landing and admin from the **Main Development (UX)** branch, styled like current main. Source `codex/admin-map-dashboard` at `cad1d2e` descends from an older baseline and includes Flutter and stale shared app/config snapshots. Integrate its final web components selectively, retaining source provenance and stable UI-LANDING-01/UI-EXPERIENCE-01/UI-HERO-02/ADMIN-MAP-01 IDs. Do not replace current source-map/clustering/pipeline work or import unrelated mobile delivery. Source ADR054/055 identifiers collide with current main, so this new ADR records integration without renumbering accepted main decisions.

Reuse current six named colors, available typography, simple borders, restrained headings, readable times and44px controls. The decorative Jakarta SVG is static and explicitly not incident geography. Landing is account-free and shows a bounded current-public page with claim-scoped source labels and explicit unavailable/demo states. Existing linked guide/privacy prerequisites explain meanings and let the user inspect/clear only known Waspada local keys with confirmation and result verification.

Empty hash and `#beranda` open landing; `#jelajah`, `#demo-sumber`, encoded detail, preferences, updates and read-only moderator demo remain supported. `#pipeline-lokal` retains exact development/demo gates and existing loopback proxy; production continues excluding that private view. UX-WEB-02 consolidates guide/privacy into help with legacy section routes. In-page skip/workspace hashes preserve the selected screen. No public record, query, geometry or source contract changes.

`#admin` lazy-loads a separate read-only web shell, JavaScript and CSS. Default is paused finite fictional simulation; its geography/process examples are labelled synthetic. API mode observes only existing public context, first20 events and GeoJSON, with30-second polling while active/visible,15-second GET deadline, bounded backoff and cancellation. It cannot inspect private L1/L2/L3 queues, model use, audit/gates or overall stack health; those values remain unavailable. Exact event/version geometry is drawn on a coordinate canvas without invented basemap, boundaries or danger radius. Source/event/observation/publication/browser-read times and dataset mode remain distinct.

These public-GET time bounds do not change15-minute local model requests or renewable private AI leases. The actual private synthetic pipeline is still inspected only through its separate development view. No authentication, provider/source activation, write endpoint, dependency, migration/grant, cloud/billing configuration, model call or deployment is required. Private admin telemetry, real-source rights, quality evaluation and hosted behavior remain gates. [Assignment and verification](../assignments/UX-WEB-01-INTEGRATION.md).

Root web181/181, workspace/tool typechecks/build/Worker dry-run, local smoke and22 headless browser groups/16 screenshots pass. Pending context now has a distinct internal loading state. Large-text fixes wrap/shrink content in landing/nav and existing source/pipeline grids without changing coordinates, acquisition or private data boundaries. Production output has separate lazy admin JS/CSS and excludes the private pipeline. Source atcad1d2e and exact isolated package/root commits are retained in the [handoff](../assignments/UX-WEB-01-INTEGRATION-HANDOFF.md). Wider Worker/DB/model suites and hosted behavior were not retested for this client-only slice.

## UX-WEB-02 refinement — 13 October 2026

User feedback identified too many navigation choices and an admin page organized around technical architecture rather than reader tasks. Keep all capabilities but group resident navigation into Beranda, Peta & laporan, Untuk Anda and Bantuan. Contextual navigation retains report/source-map and interests/updates choices. Help owns one main landmark, embeds the guide/privacy sections, preserves legacy hashes and focuses the selected section. Operator tools move to help/footer. Their links do not grant new authority; the private inspector link requires development and confirmed demo context at both composition and component boundaries.

Admin defaults to a clear purpose, report list, map and readable selected detail. Use ordinary Bahasa labels and closed native disclosures for filters, full source/time/ID metadata, complete process trace and source/request diagnostics. Simulation-only processing priority remains accessible with an explicit non-danger/non-severity caveat. Modes Contoh tampilan and Data aplikasi keep fictional examples distinct from existing public observations and never claim private operations are monitored. Source locations, unavailable/missing geometry, lifecycle, freshness, validity and separate source/event/publication/browser times retain their original meanings. Display-only annotation widths may change to fit labels; source vertices do not.

The trade-off is one extra disclosure action for technical diagnostics and contextual selection for a grouped destination, in exchange for fewer primary choices and a shorter default page. No capability or evidence is removed. Compact responsive controls preserve legible text, keyboard native summaries, 44px targets and narrow/large-text wrapping. Root web183/183, build/dry-run/smoke,23 headless groups/26 screenshots and production private-exclusion/lazy-admin checks pass after independent Luna/max review. [Exact delivery evidence](../assignments/UX-WEB-02-SIMPLIFY-HANDOFF.md). Operational authentication/private telemetry, real-source rights, model quality and hosted/manual accessibility verification remain separate gates.

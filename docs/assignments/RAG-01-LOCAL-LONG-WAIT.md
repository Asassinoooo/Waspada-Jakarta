# RAG-01-LOCAL-LONG-WAIT

Status: accepted locally 12 October 2026 after implementation, independent Luna/max review and root verification. The user requested removal of short LLM deadlines or a very long deadline; this selects the long alternative. Parent RAG-01/JOB-01 IDs remain stable. Base: 90aacea. Dependencies: accepted local pipeline/app integration, ADR-054/055/056. Domain 2.0, public v1 and local-preview-v1 unchanged. Existing installed Node 24.21.0, tsx 4.23.15, TypeScript 7.0.2, PGlite 0.5.8 only; WSL Ubuntu-26.04 for execution.

Decision: real local once/resume defaults to 900,000 ms (15 minutes) per provider request, with a processor fallback 1,000 ms later. Optional backend-only `NINEROUTER_TIMEOUT_MS` allows an integer from 1,000 through 900,000. Mock defaults, existing Worker/smoke deadlines, three-request budget, output policy, total-token/schema validation and publication authority remain unchanged. Node-only real long-wait transport reuses the existing native HTTP transport so no shorter fetch header/body timeout intervenes; provider deadline and cancellation still apply. A long request keeps its private AI lease alive through fenced renewals, without enlarging the canonical acquisition lease policy.

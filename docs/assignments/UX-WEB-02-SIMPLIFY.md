# UX-WEB-02 — grouped navigation and understandable operations

Date: 13 October2026. Status: assigned following the user's usability feedback during UX-WEB-01 integration: too many menus, dashboard difficult to understand, make it complete and universal. Baseline b9f2f61. Dependencies: accepted UX-WEB-01/source integration, current publicv1/domain2.0/local-preview-v1 and ADR058. No public/backend/model/auth/source contract change.

## Product direction

Organize by reader/admin work rather than architecture. At most four primary public choices: **Beranda**, **Peta & laporan**, **Untuk Anda**, **Bantuan**. Contextual choices group report/source-map views and interests/updates; guide/privacy become one help destination with meaningful sections. Keep bookmarked old hashes working and every existing feature accessible. Operator tools move out of resident primary navigation into a labelled **Pengelola · demo** entry/appropriate context. Private pipeline remains development/demo-only; read-only evidence review remains labelled. No nested/dropdown maze, required account, hidden lost capability or new dependency.

Admin default view explains its purpose in one sentence, shows the report list, large map and readable selected-report details. Use ordinary Bahasa: reports, sources, locations, update time, items needing attention. Replace prominent L1–L5/CRS84/probe/PUB terminology with task meanings; keep exact technical metadata behind labelled details. Collapse process/source/request diagnostics into optional sections instead of numerous always-visible panels/cards/filters. Keep the complete data/trace accessible and source/time/status distinctions intact. Mode names **Contoh tampilan** and **Data aplikasi** explain fictional simulation versus existing public reads; data application mode is not a claim of live operations. Never invent private queue/model metrics, verification, public dangerous areas or publication powers.

Reuse current colors/type/borders and mobile map/list behavior. Retain a useful empty/unavailable explanation, keyboard focus and44px actions, 320px/200% reflow. Keep geometry coordinates/versions, acquisition limits, simulator budgets/visibility, publicGET30s/15s/backoff/cancel and model15minute policy unchanged. No provider/source calls, new dependencies, install, cloud/deploy/billing/auth or writes.
